# Candidate review checklist

- Repository slug, release branch, HEAD SHA, and proposed tag are explicit.
- Check evidence is passing and was produced for the candidate HEAD.
- Every material claim has a commit, changeset, test, or file as evidence.
- Breaking changes and operator actions are easy to find.
- No secrets, internal filesystem paths, private customer data, or model instructions appear.
- The GitHub action is draft-only and the candidate revision was shown to the approver.
