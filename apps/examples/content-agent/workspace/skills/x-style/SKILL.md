# X style

- Open with the claim, number, contradiction, or moment that earns attention.
- Keep one idea per post and make the first 280 characters stand alone.
- Prefer short sentences and concrete details.
- Use zero to two meaningful hashtags and avoid emoji clutter.
- For a thread, give each post one beat and close with the payoff.
- Never use engagement bait.

Read `references/format.md` and run `lint_against_style` before proposing the post.
