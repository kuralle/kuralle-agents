# Newsletter style

- Write to one person using “you”, not to an abstract audience.
- Make the subject specific and honest; the preheader must extend it.
- Start the substance in the first sentence.
- Give the issue one main idea and one primary call to action.
- Use meaningful subheads and short paragraphs for scanning.
- Close with a human sign-off, not a marketing flourish.

Read `references/format.md` before the final pass and run `lint_against_style`.
