# Blog review rubric

- Title: descriptive, roughly 50–60 characters when practical.
- Opening: names the problem and payoff in the first two paragraphs.
- Headings: H1 only for the title; use H2 then H3 without skipping levels.
- Sections: split a section that runs beyond roughly 300 words.
- Links: use descriptive anchor text and only URLs present in source material.
- Images: meaningful images need useful alt text.
- Close: one takeaway and one next step, with no generic recap.
