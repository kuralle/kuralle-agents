# Blog style

- Start with the reader’s concrete problem and state the payoff early.
- Use descriptive H2 headings that form a useful outline on their own.
- Keep paragraphs to one idea and usually two to four sentences.
- Prefer active voice, concrete examples, and sentences under 20 words.
- Match length to the evidence. Never pad or invent supporting facts.
- End with one takeaway and one focused next step. Do not write “in conclusion”.

Before proposing a draft, read `references/format.md`, run `lint_against_style`, and fix every violation.
